# Mean curvature smoothing

Cuda implementation of "Discrete Differential-Geometry Operators for Triangulated 2-Manifolds".

![alt text](https://vincentlorant.io/posts/mean-curvature/cover_hu_7073e9fbdf84dea8.jpg)

This [Article](https://vincentlorant.io/posts/mean-curvature/) shares high-level information about the implementation.

### Setup dependencies

```
sudo apt-get update
sudo apt-get install libxinerama-dev libxcursor-dev libc++-dev libc++abi-dev libglu1-mesa-dev libopen3d-dev
```

### Setup Open3D

From packet manager
```
sudo apt-get update
sudo apt-get install libopen3d
```

From source
https://www.open3d.org/docs/release/compilation.html
